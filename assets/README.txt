Car damage-diagram artwork (Trade-In → État de la carrosserie)
================================================================

Drop your own car outline images here to replace the built-in drawings.
Use images you have the right to use (purchased, or free/royalty-free license).

File names (SVG or PNG with transparent background works best):

  car-side.svg   -> used for BOTH "Côté conducteur" and "Côté passager"
                    (the passenger side is auto-mirrored from this one)
  car-front.svg  -> used for "Avant"
  car-rear.svg   -> used for "Arrière"

Placeholder vector drawings ship in these files already. Replace them with
your own artwork (same names), OR use the in-app button under the damage pad
("Remplacer le dessin de cette vue par mon image") which saves per device and
overrides these files without touching the folder.

- Any view without a matching file falls back to the built-in line drawing,
  so you can add them one at a time.
- Images are auto-scaled to fit the pad; a wide side image (roughly 2:1)
  looks best. You draw the red damage marks on top either way.
- After adding files, reload Snake's Hustle (F5).
