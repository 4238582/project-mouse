☁️ Cloud Sync Setup
Follow these steps to enable real-time sync between your iPhone and computer. It's free and takes about 5 minutes.
  • 1
    Go to firebase.google.com and sign in with your Google account
  • 2
    Click Create a project → name it "ProjectMouse" → Continue
  • 3
    Go to Build → Firestore Database → Create database → Start in test mode
  • 4
    Go to Build → Storage → Get started → Done
  • 5
    Go to Project Settings → Your apps → Web icon → Register app → Copy the config and paste below
